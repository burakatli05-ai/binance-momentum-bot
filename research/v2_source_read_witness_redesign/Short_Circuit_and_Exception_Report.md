# Okuma ve exception sonuçları
Exact kaynak fonksiyon body'leri ile hash doğrulanmış AST kopyası karşılaştırıldı. Fixture collaborator'ları gerçek DB/notify yerine yalnız aynı sıralı side-effect transcript'ini tutar. AST karşılaştırma operatörleri yeniden yazılmadı.

İlk tam adayda25 senaryo yeni NameError nedeniyle farklılaştı. Bu çalışma için exception equality kapısı BAŞARISIZDIR. Sonraki anchor düzeltmesiyle32 senaryo tanılayıcı olarak eşleşti; tarihsel failure silinmedi.

Düzeltilmiş kopyada FAST=true lower global read0 ve NOT_READ_SHORT_CIRCUIT; FAST=false lower read1. Gate'in önceki and koşulu false ise cap read0. Qualification label false ise qualification min_score read0, SQL read1. Notify flag false ise notify min_score read0. Qualification/SQL/event/notify ayrı locals ve ayrı loads olarak kaldı;90→96,90→97,90→95→90→95 ve same-value republish örnekleri ayrı değerler verdi.

Invalid global type, reflected comparison exception, property exception, scorer exception, SQL failure, event failure, notification failure ve mevcut StepLock failure yolu karşılaştırıldı. Type/message, mevcut catch sonucu, return, branch/side-effect transcript, cfg/min_score read sırası ve adedi sonuç JSON'dadır. Traceback/frame/refcount identity ispatı değildir. Exception yüzünden sideband dönmeyen fonksiyonun operandları UNKNOWN_EXCEPTION_OR_GAP kalır; yeniden okunmaz.

Karşılaştırma sonuçları gate return, scorer label/result, selector qualified ve explicit raising comparator ile gözlenmiştir; her ara builtin arithmetic/comparison için ayrı tracer çalıştırılmadı. Added instruction timing, resource exhaustion ve custom finalizer equivalence model dışıdır.
